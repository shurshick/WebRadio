# 📻 Sonara Radio v2.2

**Sonara Radio** — это современный, быстрый и независимый веб-плеер для прослушивания тысяч радиостанций со всего мира. Приложение построено как **Progressive Web App (PWA)** в виде единого `index.html`, работающего на базе открытого каталога [Radio Browser API](https://www.radio-browser.info/).

## ✨ Ключевые фишки и особенности

### 🚀 Архитектура и Производительность
- **Progressive Web App (PWA):** Благодаря `manifest.json` и `sw.js` (Service Worker), радио можно установить как полноценное приложение на Windows, macOS, Android и iOS прямо из браузера. Кэширование интерфейса обеспечивает мгновенный запуск.
- **Precompiled Tailwind CSS:** Полный отказ от тяжелых CDN-компиляторов. Стили скомпилированы и встроены в HTML (Zero runtime cost).
- **HLS (.m3u8) Support:** Встроенная библиотека `hls.js` автоматически перехватывает HLS-потоки и декодирует их. Это позволяет слушать современные стримы в десктопных браузерах Windows, которые изначально не поддерживают этот формат.
- **Failover API:** Встроенный механизм отказоустойчивости переключается между зеркалами API (de1, nl1, at1) при таймаутах, обеспечивая 99.9% доступности каталога.

### 🎨 Интерфейс и UX
- **Кинематографичные анимации:** Использование современного аппаратного **View Transitions API** для плавного, бесшовного (cross-fade) переключения между разделами и вкладками без сторонних JS-библиотек анимаций.
- **Умные SVG-заглушки (Smart Fallbacks):** Если у станции отсутствует логотип или сервер радиостанции отдал нерабочую картинку (битая ссылка), Sonara Radio "на лету" генерирует красивую градиентную SVG-иконку с первой буквой названия станции.
- **Тёмная тема (Glassmorphism):** Стильный дизайн с использованием эффекта матового стекла (`backdrop-blur`), неоновых акцентов и моноширинных шрифтов для битрейта.

### 🎛 Функционал плеера
- **Динамические фильтры:** Список из более чем 150 стран подгружается напрямую из API. Рядом доступен **фильтр битрейта**, позволяющий в один клик убрать станции с низким качеством (например, оставить только `320 kbps`).
- **Media Session API:** Полная интеграция с операционной системой. При сворачивании браузера в Windows или на экране блокировки Android отображаются кнопки управления (Play/Pause, Next, Prev), а также название станции и обложка.
- **Sleep Timer & PC Shutdown:** Уникальная функция для десктопа! Вы можете установить таймер сна. По истечении времени плеер может не только остановить музыку, но и **выключить компьютер**.
  - *(Для активации выключения ПК приложение генерирует безопасный `install-shutdown.bat`, который регистрирует локальный протокол `sonarashutdown:` и кладет исполняемый `.vbs` скрипт в скрытую системную папку `%LOCALAPPDATA%`. **Безопасность:** перед выключением скрипт выведет системное окно с таймаутом на 30 секунд для подтверждения или отмены действия)*.
- **Импорт / Экспорт Избранного:** Сохранение любимых радиостанций в локальный `.json` файл для удобного переноса между устройствами или браузерами.

## 🚀 Установка и Использование

Sonara Radio не требует базы данных или сложной установки.

1. **Для стандартного использования** просто откройте `index.html` в любом современном браузере. Приложение полностью работоспособно при прямом локальном запуске (`file://`).
2. **Для установки как PWA (на рабочий стол/экран телефона):** браузеры требуют безопасный контекст (HTTPS или `localhost`). Обычный запуск через `file://` для PWA не подойдёт. Запустите любой локальный HTTP-сервер, например:
   - `npx http-server` (в папке проекта)
   - Расширение Live Server в VSCode
   - `python -m http.server`
   После этого перейдите по адресу `localhost` и в браузере появится кнопка установки приложения.
3. **Для активации функции "Выключить ПК" (только для Windows):**
   - Откройте настройки/информацию в приложении.
   - Скачайте `install-shutdown.bat`.
   - Запустите скачанный `.bat` файл от имени пользователя (он создаст обработчик протокола).

## 📜 История версий (Changelog)

### v2.2 (Текущая версия: Глобальный рефакторинг и оптимизация)
- **[Оптимизация]** Полный отказ от компиляции Tailwind CSS в браузере. Стили минифицированы и встроены напрямую, что убрало задержку при первом рендере.
- **[Оптимизация]** Логотип приложения (Base64) пережат с 1024x1024 (424 КБ) до Retina-ready 256x256 (101 КБ) с сохранением идентичного визуала.
- **[Архитектура]** Добавлена поддержка Progressive Web App (PWA) с автономным кэшированием (Service Worker) и `manifest.json` для установки на устройства.
- **[Плеер]** Интегрирована библиотека `hls.js` для нативной поддержки `.m3u8` стримов в десктопных браузерах Windows (Safari fallback поддерживался по умолчанию).
- **[Плеер]** Устранен критический баг (`InvalidStateError`) при остановке live-потоков (исправлена логика `currentTime = 0`).
- **[UX/UI]** На карточки станций добавлена статистика: количество прослушиваний и лайков (голосов), подтягиваемая из API Radio Browser.\n- **[UX/UI]** Внедрен аппаратный **View Transitions API** для плавного (cross-fade) переключения вкладок меню без рывков интерфейса.
- **[UX/UI]** Добавлен динамический генератор SVG-заглушек (с градиентом и первой буквой) для станций, у которых сломан или отсутствует логотип в API Radio Browser.
- **[Фильтры]** Локальный фильтр стран заменен на динамический API-запрос (`/countries`), подтягивающий топ-150 популярных стран мира.
- **[Фильтры]** Добавлен выпадающий фильтр качества потока (отбрасывание станций с битрейтом ниже выбранного, вплоть до 320 kbps).
- **[Производительность]** Загрузка жанровых подборок переведена с медленной последовательной очереди на параллельную загрузку (`Promise.all`), что ускорило рендер раздела в 6-8 раз.
- **[Багфикс]** Кнопка Play теперь корректно возобновляет последнюю прослушанную станцию после перезагрузки страницы (восстановление подключения без бесконечной буферизации).\n- **[Багфикс]** Точечное обновление состояний DOM (добавлен `data-uuid`). Выделение активной станции и добавление в "Избранное" больше не вызывают перерисовку всей сетки станций, сохраняя сложную группировку жанров.
- **[Безопасность]** VBS-скрипт для выключения ПК (`install-shutdown.bat`) переведен из опасной относительной директории `%~dp0` в системную защищенную папку `%LOCALAPPDATA%\SonaraRadio`.


- **[Новая фича]** Вкладка "Недавние" (History): автоматическое сохранение истории 20 последних прослушанных станций.
- **[Новая фича]** "Свой поток" (Custom Stations): возможность добавить и сохранить любую прямую ссылку на аудиопоток (mp3/m3u8), если её нет в глобальном каталоге.
- **[Инновация]** Гибридный смарт-эквалайзер: автоматическое определение поддержки CORS у трансляции. Если CORS поддерживается — активируется настоящий Web Audio API визуализатор спектра. В противном случае происходит бесшовный fallback на красивую CSS-анимацию без прерывания звука.
