# 📻 Sonara Radio v2.2

**Sonara Radio** — это современный, быстрый и независимый веб-плеер для прослушивания тысяч радиостанций со всего мира. Приложение построено как **Progressive Web App (PWA)** в виде единого `index.html`, работающего на базе открытого каталога [Radio Browser API](https://www.radio-browser.info/).

## ✨ Ключевые фишки и особенности

### 🚀 Архитектура и Производительность
- **Progressive Web App (PWA):** Благодаря `manifest.json` и `sw.js` (Service Worker), радио можно установить как полноценное приложение на Windows, macOS, Android и iOS прямо из браузера. Кэширование интерфейса обеспечивает мгновенный запуск.
- **Precompiled Tailwind CSS:** Полный отказ от тяжелых CDN-компиляторов. Стили скомпилированы и встроены в HTML (Zero runtime cost).
- **HLS (.m3u8) Support:** Встроенная библиотека `hls.js` автоматически перехватывает HLS-потоки и декодирует их. Это позволяет слушать современные стримы в десктопных браузерах Windows, которые изначально не поддерживают этот формат.
- **Failover API & Auto-discovery:** Встроенный механизм отказоустойчивости переключается между зеркалами API (de1, nl1, at1) и автоматически обнаруживает доступные серверы каталога при старте.

### 🎨 Интерфейс и UX
- **Кинематографичные анимации:** Использование современного аппаратного **View Transitions API** для плавного, бесшовного (cross-fade) переключения между разделами и вкладками без сторонних JS-библиотек анимаций.
- **Умные SVG-заглушки (Smart Fallbacks):** Если у станции отсутствует логотип или сервер радиостанции отдал нерабочую картинку (битая ссылка), Sonara Radio "на лету" генерирует красивую градиентную SVG-иконку с первой буквой названия станции.
- **Тёмная тема (Glassmorphism):** Стильный дизайн с использованием эффекта матового стекла (`backdrop-blur`), неоновых акцентов и моноширинных шрифтов для битрейта.
- **Динамический CSS-эквалайзер:** Плавная аппаратная анимация спектра, синхронизированная со статусом воспроизведения, работающая со всеми аудиопотоками без задержек и ограничений CORS.

### 🎛 Функционал плеера
- **Быстрый комбинированный поиск:** Поиск по названию станций и жанровым тегам с защитой от race-condition при быстром наборе текста.
- **Динамические фильтры:** Фильтрация по ISO кодам стран и битрейту (отбрасывание станций с низким качеством вплоть до 320 kbps), работающая мгновенно в контексте любого выбранного раздела.
- **История и Свои потоки:** Автоматическое сохранение 20 последних прослушанных станций и возможность добавления собственных `.mp3` / `.m3u8` потоков.
- **Media Session API:** Полная интеграция с операционной системой. При сворачивании браузера в Windows или на экране блокировки Android отображаются кнопки управления (Play/Pause, Next, Prev), а также название станции и обложка.
- **Sleep Timer & Безопасное выключение ПК:** Таймер сна с возможностью остановки воспроизведения или мягкого выключения компьютера. Перед выключением пользователю выводится диалог с 25-30 секундным таймаутом на отмену действия. Предусмотрен скрипт полного удаления (`uninstall-shutdown.bat`).
- **Резервное копирование (Экспорт / Импорт):** Полное сохранение как избранных, так и собственных добавленных станций в JSON с валидацией структуры данных.

## 🚀 Установка и Использование

Sonara Radio не требует базы данных или сложной установки.

1. **Для стандартного использования** просто откройте `index.html` в любом современном браузере. Приложение полностью работоспособно при прямом локальном запуске (`file://`).
2. **Для установки как PWA (на рабочий стол/экран телефона):** браузеры требуют безопасный контекст (HTTPS или `localhost`). Обычный запуск через `file://` для PWA не подойдёт. Запустите любой локальный HTTP-сервер, например:
   - `npx http-server` (в папке проекта)
   - Расширение Live Server в VSCode
   - `python -m http.server`
   После этого перейдите по адресу `localhost` и в браузере появится кнопка установки приложения.
3. **Для активации функции "Выключить ПК" (только для Windows):**
   - Запустите `install-shutdown.bat` от имени пользователя (он создаст обработчик безопасного протокола в `%LOCALAPPDATA%\SonaraRadio`).
   - Для деинсталляции и очистки реестра запустите `uninstall-shutdown.bat`.

## 🧪 Тестирование и CI

В репозитории настроен автоматический тестовый набор и GitHub Actions CI:

```bash
node tests/run-tests.js
```

Тесты проверяют:
- Валидность JS-синтаксиса и HTML-структуры
- Корректность и валидность `manifest.json` и `sw.js`
- Наличие и соответствие размеров PWA-иконок (192x192, 256x256, 512x512)
- Защиту от DOM XSS инъекций
- Безопасность механизма выключения ПК (наличие таймаута и подтверждения)
- Защиту сетевых запросов от race conditions

## 📜 История версий (Changelog)

### v2.2 (Текущая стабильная версия)
- **[Безопасность]** Устранена уязвимость DOM XSS: все пользовательские поисковые строки, теги и данные станций экранируются через `setSectionTitle()` и `escapeHTML()`.
- **[Безопасность]** Улучшена безопасность выключения ПК: добавлен обязательный предварительный браузерный диалог подтверждения, системный диалог с 30-секундным таймаутом на отмену через `shutdown /a`, убран флаг принудительного завершения `/f`, добавлен `uninstall-shutdown.bat`.
- **[Стабильность]** Защита от race conditions при сетевых запросах: внедрен `activeRequestId` в поиск, переключение вкладок и тегов; отложенный поиск очищается по `clearTimeout(searchTimeout)` при смене раздела.
- **[Плеер]** Улучшена обработка фатальных ошибок HLS: автоматический сброс состояния плеера и мягкий переход к следующей рабочей станции.
- **[UX/UI]** Исправлен генератор fallback-аватарок станций: карточки получили `data-name`, SVG-иконки корректно отображают первую букву названия станции.
- **[Фильтры]** Фильтр по странам теперь применяется мгновенно поверх текущего раздела без перезаписи локального контекста Избранного, Истории или Поиска.
- **[Данные]** Улучшено резервное копирование: экспорт и импорт сохраняют как избранные UUID, так и пользовательские добавленные станции (`customStations`) с валидацией структуры данных.
- **[Данные]** Корректное восстановление последней прослушанной станции после перезагрузки страницы (включая кастомные потоки).
- **[Архитектура]** Service Worker обновлен: полное кэширование иконок 192px/256px/512px, ускоренная активация через `skipWaiting()` и `clients.claim()`.
- **[Качество]** Добавлены автоматические тесты `tests/run-tests.js` и GitHub Actions CI.

### v1.0 (Первый релиз)
- Базовая реализация плеера на Vanilla JavaScript и Tailwind CSS.
- Подключение к публичному каталогу Radio Browser API.
- Функция таймера сна с локальным протоколом `sonarashutdown:`.
- Сохранение избранных радиостанций в `localStorage` браузера.
